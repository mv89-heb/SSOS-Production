# ייבוא היסטורי מרוכז — חשבוניות ותעודות משלוח

הכלי נמצא תחת **הגדרות → כלים חד־פעמיים → ייבוא היסטורי מרוכז** ונועד לתיעוד מסמכים שכבר התקבלו בעבר.

## תהליך עבודה
1. בוחרים אצווה של קובצי PDF ותמונות. מנוע מודיעין המסמכים הקיים מחלץ מהם נתונים באופן זמני.
2. מוסיפים לאצווה רק מסמכים שזוהו כחשבונית או כתעודת משלוח.
3. בודקים ספק, מספר מסמך, תאריך, סכום, שורות מוצרים וכפילויות אפשריות.
4. נותנים לכל מסמך אסמכתת הזמנה היסטורית משותפת עם מסמכים השייכים לאותה הזמנה. אין להשתמש אוטומטית במספר המסמך כתחליף למספר הזמנה.
5. פותרים את כל החריגים ושומרים את הבדיקה הידנית.
6. מאשרים את האצווה. נוצרת רשומת הזמנה היסטורית נפרדת לכל שילוב של ספק ואסמכתת הזמנה.

## גבולות בטיחות
- קובצי המקור אינם נשמרים כקבצים מצורפים. נשמרים רק שדות שחולצו, שורות המסמך, שם הקובץ לצורכי עקיבות, תוצאות בדיקה והיסטוריית הפעולות.
- מסמכים היסטוריים נשמרים בטבלאות נפרדות ואינם יוצרים רשומות בטבלאות orders או receipts.
- אישור אצווה אינו משנה מלאי, אינו רושם תשלום, אינו מאשר חשבונית לתשלום ואינו יוצר תזכורות או התראות.
- סכום שלא זוהה נשאר לא ידוע; הוא אינו מוחלף באפס.
- חשד לכפילות, ספק חסר, מספר מסמך חסר, תאריך חסר או היעדר אסמכתת הזמנה מחייבים בדיקה לפני סיום.
- סיום אצווה הוא פעולה אידמפוטנטית: קריאה חוזרת אינה יוצרת הזמנות היסטוריות כפולות.
- הרשומות מבודדות לפי ארגון (tenant), ונדרשת הרשאת מנהל.

## מגבלות ידועות
- האצווה אינה מחליפה הנהלת חשבונות או מסמך המקור הרשמי.
- מסמך הכולל כמה ספקים או שורות לא מזוהות דורש בדיקה ידנית לפני אישור.
- הקיבוץ להזמנה נעשה רק לפי ספק ושדה אסמכתת ההזמנה שהמשתמש בדק; המערכת אינה מנחשת שקילות בין מספרי מסמכים.
