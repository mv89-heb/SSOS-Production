# הרשאות משתמשים ב-SSOS

## עקרונות
- הרשאות נאכפות בשרת, ולא רק באמצעות הסתרת כפתורים בממשק.
- הרשאות פרטניות הן חריגות למשתמש; כאשר אין חריגה, יורשים את ברירות המחדל של התפקיד.
- מנהל מערכת הוא היחיד שמנהל משתמשים והרשאות.
- כל שינוי תפקיד או הרשאה יתועד ביומן הביקורת.
- אין לאפשר למנהל המערכת האחרון בארגון לאבד גישת ניהול.
- שינויי הרשאות אינם משנים נתונים עסקיים קיימים.

## אזורי הרשאות
- הזמנות: צפייה, יצירה, עריכה, אישור, סימון כנשלחה, השלמה וביטול.
- ספקים ומוצרים: צפייה, יצירה, עריכה והשבתה.
- מלאי: צפייה, ספירה ועדכון.
- מסמכים וייבוא: צפייה, העלאה, ניתוח, אישור שורות ומחיקה.
- דוחות: צפייה וייצוא.
- משתמשים: צפייה, יצירה, שינוי תפקיד, שינוי הרשאות והפעלה/השבתה.
- הגדרות ויומן ביקורת: צפייה וניהול לפי הרשאה.

## תנאי קבלה
1. כל נקודת API משנה-נתונים בודקת הרשאה בשרת.
2. ברירת המחדל של משתמשים קיימים שומרת על ההתנהגות הקיימת לפי תפקיד.
3. בדיקות של עובד, מנהל ומנהל מערכת מכסות גישה מותרת וחסומה.
4. ניסיון לגשת לנתוני ארגון אחר נשאר חסום.
5. שינויי הרשאות נרשמים ביומן ביקורת.
6. מסך ניהול מציג הרשאות יעילות ומאפשר להחזיר הרשאה לברירת המחדל של התפקיד.
