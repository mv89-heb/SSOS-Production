# מחסן ומלאי

המסך `/dashboard/inventory` הוא מסך רספונסיבי אחד לעבודה מהטלפון ומהמחשב.

- בטלפון: חיפוש/בחירת מוצר, הזנת ספירה פיזית ושמירה.
- השמירה יוצרת תנועת `count` ומעדכנת את `current_stock` דרך ה־API הקיים.
- במחשב: אותו מסך מציג מלאי נוכחי והמלצות המבוססות על היסטוריית הספירות.
- אין נתונים מומצאים: עד שאין מספיק ספירות אמיתיות, ההמלצה נשארת `insufficient_data`.
